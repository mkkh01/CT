# تدقيق ترقية النظام إلى محرك احترافي

## تاريخ التدقيق
2026-08-12

## الحالة الفعلية قبل المتابعة

| البند | الحالة الفعلية | الملاحظة |
|---|---|---|
| WebSocket وREST fallback | موصل وموجود في النسخة المنشورة | healthz السابق أثبت جاهزية 1H/4H في Render |
| الإطار التنفيذي | 1H فقط | `Settings` لا يحتوي trigger timeframe منفصلاً |
| الإطار الأعلى | 4H | مستخدم فعلياً كفلتر الاتجاه |
| إطار 15m/30m | غير منفذ | لا يوجد في config أو عميل Binance أو runtime |
| Market Structure | تعديل محلي غير مدفوع | الدالة الحالية تقسّم آخر 10 شموع إلى نصفين، وليست swing-point engine كاملاً |
| BB Squeeze | تعديل محلي غير مدفوع | يُحسب ويُعرض في diagnostics فقط، وليس شرط دخول فعلياً |
| شرط الشموع | ما زال شرطاً إلزامياً | لا تزال أنماط الشموع جزءاً من شروط الإشارة |
| Trailing Stop | تعديل محلي غير مدفوع | ليس ATR-based؛ يبدأ عند ربح 2% ويجرّ الوقف إلى نصف الربح |
| ATR Trailing Stop | غير منفذ | لا توجد حقول إعداد أو حالة وقف متحرك في النماذج/قاعدة البيانات |
| Correlation Filter | غير منفذ | لا توجد دالة أو بيانات ارتباط أو شرط رفض |
| مقاييس Sharpe/Drawdown | غير منفذة | لا توجد حسابات أو حقول في API/الداشبورد |
| تشخيصات احترافية في Signal | غير محفوظة كحقول منظمة | تُوجد داخل `indicator_metrics` في أحداث القرار فقط، بينما نموذج Signal محدود |
| اختبارات الترقية | غير كافية | 28 اختباراً، ولا تغطي 15m أو BB Squeeze أو structure أو trailing stop |
| النشر | آخر نسخة المنشورة قبل التعديلات المحلية | `origin/main` عند `e179e2a`، و`strategy.py` و`virtual_trading.py` معدلان محلياً فقط |

## قرارات المتابعة

1. عدم إضافة 15m كشرط أعمى؛ سيُنفذ كـ trigger اختياري واضح الإعداد، مع الحفاظ على 1H/4H كنسخة آمنة افتراضية حتى تُختبر الإشارات.
2. عدم اعتبار BB Squeeze شرطاً إلزامياً قبل تحديد تعريف قابل للاختبار للخروج من الانكماش؛ سيُسجل كتشخيص وفلتر اختياري مع سبب الرفض.
3. استبدال الوقف المحلي الحالي بوقف ATR موثق، مع اختبارات تمنع تحرك الوقف إلى أسفل أو تجاوز الهدف.
4. إضافة اختبارات قبل أي نشر، ثم تشغيل نسخة محلية وقراءة healthz والـ Summary Cycle قبل الدفع.
5. لا توجد أوامر Binance حقيقية في أي مرحلة؛ كل التغييرات تبقى توصيات وصفقات افتراضية فقط.
